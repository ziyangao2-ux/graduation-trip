# 产品设计依据与取舍

调研日期：2026-10-10。依据公开产品与帮助页面，不涉及付费账户内流程。

## 参考产品

- [JoinMyTrip：How it works](https://www.joinmytrip.com/how-it-works)：目的地、时间、活动筛选与参团流程；借鉴“发现 → 了解 → 加入”的信息顺序。
- [JoinMyTrip：TripMates FAQ](https://www.joinmytrip.com/en/help/faq-collection/tripmates%2CW2f3bCoAAP7jtqzo)：费用包含项、取消政策与行前沟通；借鉴团规与参团前信息透明。
- [GAFFL：寻找旅伴](https://www.gogaffl.com/find-a-travel-buddy/lekki-ikate-and-environs)：目的地 → 查看同行 → 联系 → 共同旅行；借鉴目的地优先的发现路径。
- [GAFFL：Connect 帮助](https://help.gogaffl.com/category/joining-trips/)：类型和日期筛选、连接后的共同规划；多人沟通列为未来能力。

## 本次实现

保留机场出发屏的识别感：冷纸白页面、深靛蓝列表、珊瑚色主操作、青绿招募状态、琥珀色最后余位。桌面使用可比较的列表，手机完整显示目的地、日期、预算和人数。

四步发布：目的地、时间、预算人数、团规标签。推荐目的地与分组标签减少输入。切换地区清空目的地，修改日期清空时长。最多五个标签，超限明确提示。

草稿自动保存，发布前显示所选信息，发布后进入“我的团”。加入与退出更新名额；团长不能重复参团；取消与过期行程不再招募。团规模板可切换，不重复追加。

分享采用链接快照，静态部署也能查看自建行程。明确提示快照不等于跨设备同步。成员与信用分标记为示例，不暗示已认证身份。

## 正式多人版本

需要账户与共享数据库、团长和成员权限、服务端原子参团与退出、可撤销邀请、沟通通知、举报管理、隐私控制，以及有真实数据依据的履约评价。以上完成前，演示操作不构成真实出行承诺。
