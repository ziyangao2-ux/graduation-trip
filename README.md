# 出发 · 拼团

一个以「组队」为核心的**毕业旅行拼团平台**产品原型。

帮你找到预算、时间、兴趣都合拍的人，把「成团」这件事办成。

## 产品定位

- **公开拼团平台**：陌生人按目的地 / 时间 / 预算撮合成团
- **精品小团**：4–8 人
- **核心机制**：成团状态机 + 信用分（承诺制，不托管资金）

## 功能

- **出发屏（发现流）**：机场出发时刻表式的团列表，搜索 + 地区筛选 + 余位进度
- **团详情**：团规、行程框架（主线 + 自由活动）、成员信用、一键加入
- **发起拼团**：分步表单（目的地 → 时间 → 预算/人数 → 团规）
- **我的团**：我发起的 / 我加入的，成团进度可视化
- **信用分主页**：个人信用、发起/加入统计

## 本地运行

直接打开 `index.html`，或起一个静态服务：

```bash
python -m http.server 8000
```

数据存于浏览器 `localStorage`，首次访问会载入示例数据。
